# Community Submissions

Drafts for adding sol-agent-wallet to the major MCP and Solana lists. Each file contains:

- **Target repo + URL**
- **Exact PR title**
- **PR body** (copy-paste ready)
- **The diff entry** — the exact line(s) to add and where

Before opening each PR:

1. Re-clone the target repo fresh, branch off `main` (or whatever the default is).
2. Locate the section header named in the "Where" field.
3. Insert the entry alphabetically unless the section is curated by date.
4. Run any linter the repo has (markdownlint, awesome-lint).
5. Open the PR with the title + body from the draft.
