## Sequencing (recommended)

1. **Day 0**: PyPI release goes live. Confirm `uvx sol-agent-wallet` works from a clean machine.
2. **Day 1 morning (PT/JST overlap, ~17:00 JST / 00:00 PT)**: Post the X thread.
3. **Day 1 +2h**: Post in Solana Tech Discord `#showcase`.
4. **Day 1 +4h**: r/solana.
5. **Day 2 morning (PT)**: Show HN.
6. **Day 3**: LinkedIn.

Don't bunch them — each post should have its own peak so you can respond to comments without splitting attention.
